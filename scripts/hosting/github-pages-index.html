Install CHV

CHV is a Linux-first, cloud-image-first virtualization platform for sovereign private cloud and edge environments.

Run the all-in-one installer on a fresh Ubuntu server with root access:

curl -fsSL https://raw.githubusercontent.com/o3kio/chv/main/scripts/install.sh | sudo bash -s

Or pin a specific version:

curl -fsSL https://raw.githubusercontent.com/o3kio/chv/main/scripts/install.sh | sudo INSTALL_CHV_VERSION=0.3.0 bash -s

The installer requires bash; the old | sh - form does not work. Supported today: one host, Cloud Hypervisor v53.0, Ubuntu amd64 — no multi-host, HA, or backup/restore.

Read the full deployment guide for manual setup and build instructions.
